# cv-react-simon-toro

Hoja de vida modular en React (Vite). Proyecto realizado como actividad GA1-220501096-03-AA1-EV05.

## Ejecutar localmente

1. `npm install`
2. `npm run dev`
3. Abrir `http://localhost:5173` (o la URL que muestre Vite).
